# Changelog

## v0.1.0-community-protocol

Initial public protocol package for evidence-first vehicle diagnostic AI agents.

### Added

- Public `AGENTS.md` protocol.
- Public read-only `SKILL.md`.
- Chinese and English documentation.
- Evidence-first diagnostic report structure.
- Open-core boundary notes.
- Safety rules for read-only diagnostic workflows.
- Demo and architecture documentation.
- GitHub issue templates.

### Scope

This release is a protocol package and reference workflow. It is not a complete production vehicle diagnostic product.
