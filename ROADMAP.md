# CarClaw Roadmap

## Current Focus

CarClaw is focused on defining a safe, evidence-first workflow protocol for vehicle diagnostic AI agents.

## Near Term

- Improve the public diagnostic report template.
- Add more mock DTC cases.
- Add schema examples for evidence records.
- Add MCP adapter examples.
- Add more safety boundary examples.

## Mid Term

- Add protocol conformance checks.
- Add red-team examples for unsafe diagnostic responses.
- Add a reference mock MCP server.
- Add multi-agent review patterns for diagnosis and evidence checking.

## Later

- Define optional production extension points.
- Add deployment notes for private knowledge bases.
- Add integration examples for repair workflow systems.

## Non-goals

- CarClaw does not include proprietary service manuals.
- CarClaw does not include real vehicle control by default.
- CarClaw does not replace qualified technicians.
- CarClaw does not provide legal or compliance certification.
