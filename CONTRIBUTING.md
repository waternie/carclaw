# Contributing to CarClaw

Thanks for helping improve the CarClaw community protocol.

## Good First Contributions

- Add mock DTC cases.
- Improve evidence field schemas.
- Improve the diagnostic report template.
- Add safety boundary examples.
- Add MCP adapter examples.
- Improve Chinese or English documentation.

## Contribution Principles

- Keep the public workflow evidence-first.
- Separate facts from AI inference.
- Do not add proprietary service manual content.
- Do not add customer data.
- Do not add real ECU configuration, CAN ID databases, or hardware secrets.
- Do not add write operations to the default community skill.

## Pull Request Guidelines

- Keep changes focused.
- Explain the diagnostic workflow impact.
- Add examples when changing protocol or report structure.
- Update both Chinese and English docs when the public protocol changes.
- Do not commit credentials or private environment files.

## Issue Guidelines

Useful issues include:

- DTC or symptom workflow gaps.
- Missing evidence fields.
- Ambiguous safety boundaries.
- Tool contract adaptation problems.
- Agent runtime integration notes.
