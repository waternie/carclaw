# CarClaw v0.1.0 Community Protocol Release Notes

## Suggested GitHub Release Title

```text
CarClaw v0.1.0 - Evidence-first vehicle diagnostic agent protocol
```

## Suggested GitHub Release Body

```markdown
CarClaw v0.1.0 is the first public community protocol package for evidence-first vehicle diagnostic AI agents.

This release includes:

- Public AGENTS.md protocol
- Read-only vehicle diagnostic skill
- Evidence-first diagnostic report structure
- Safety boundaries for community workflows
- Open-core boundary notes
- Demo and architecture documentation
- GitHub issue templates

CarClaw is not a production vehicle diagnostic product. It is a public workflow protocol for building safer, auditable diagnostic agents.
```
